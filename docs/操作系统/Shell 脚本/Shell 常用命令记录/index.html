Shell 常用命令记录

最近逐渐发现 Linux 还有好多开发用到的命令不太熟悉，这里专门记录一下

ldd 打印动态库​

Linux 中可以使用 ldd 列出动态库依赖关系，如下打印 Go Build 出来的文件的依赖库

$ ldd /home/alsritter/go/bin/middlewomen    
> 输出       
        linux-vdso.so.1 (0x00007fffa7ff4000)
        libpthread.so.0 => /lib/x86_64-linux-gnu/libpthread.so.0 (0x00007f03f435c000)
        libc.so.6 => /lib/x86_64-linux-gnu/libc.so.6 (0x00007f03f419b000)
        /lib64/ld-linux-x86-64.so.2 (0x00007f03f43a2000)

可以发现只依赖了标准的 so、libc 库和线程 pthread 库（都是 Linux 的标准库）

time 打印运行时间​

linux 下 time 命令可以获取到一个程序的执行时间，包括程序的实际运行时间(real time)，以及程序运行在用户态的时间(user time)和内核态的时间(sys time)

date 时间命令​

这个命令就是用来返回当前时间，这里主要介绍它的格式化输出

时间方面：

% : 印出 %
%n : 下一行
%t : 跳格
%H : 小时(00..23)
%I : 小时(01..12)
%k : 小时(0..23)
%l : 小时(1..12)
%M : 分钟(00..59)
%p : 显示本地 AM 或 PM
%r : 直接显示时间 (12 小时制，格式为 hh:mm:ss [AP]M)
%s : 从 1970 年 1 月 1 日 00:00:00 UTC 到目前为止的秒数
%S : 秒(00..61)
%T : 直接显示时间 (24 小时制)
%X : 相当于 %H:%M:%S
%Z : 显示时区

日期方面：

%a : 星期几 (Sun..Sat)
%A : 星期几 (Sunday..Saturday)
%b : 月份 (Jan..Dec)
%B : 月份 (January..December)
%c : 直接显示日期与时间
%d : 日 (01..31)
%D : 直接显示日期 (mm/dd/yy)
%h : 同 %b
%j : 一年中的第几天 (001..366)
%m : 月份 (01..12)
%U : 一年中的第几周 (00..53) (以 Sunday 为一周的第一天的情形)
%w : 一周中的第几天 (0..6)
%W : 一年中的第几周 (00..53) (以 Monday 为一周的第一天的情形)
%x : 直接显示日期 (mm/dd/yy)
%y : 年份的最后两位数字 (00.99)
%Y : 完整年份 (0000..9999)

使用例

$ date
# Fri 11 Feb 2022 10:13:25 AM CST
$ date '+%c'  # 显示完整的时间
# Fri 11 Feb 2022 10:13:40 AM CST
$ date '+%D' # 显示数字日期，年份两位数表示
# 02/11/22
$ date '+%x' # 显示日期，年份用四位数表示
# 02/11/2022
$ date '+%T' # 显示24小时的格式
# 10:16:57
$ date '+%X' 
# 10:17:35 AM

按自己的格式输出

$ date '+%T%n%D'
10:18:48
02/11/22

source 命令​

source 命令用法

source FileName

也可以简写为：

. FileName

两种写法的效果相同。对于第二种写法，注意点号 . 和文件名中间有一个空格。

这个命令其实只是简单地读取脚本里面的语句依次在当前 shell 里面执行，没有建立新的子 shell。那么脚本里面所有新建、改变变量的语句都会保存在当前 shell 里面。

source 命令会强制执行脚本文件中的全部命令，而忽略脚本文件的权限。
