13 种 Prompt 用法

在ChatGPT中，prompt 通常指的是一个输入的文本段落或短语，作为生成模型输出的起点或引导。prompt 可以是一个问题、一段文字描述、一段对话或任何形式的文本输入，模型会基于 prompt 所提供的上下文和语义信息，生成相应的输出文本。

以下是一些常见的 prompt 用法：

1、解释​

这种模式下，你输入的内容是让ChatGPT对某个概念或理论进行解释和说明。他的主要作用是对各种概念做定义。
